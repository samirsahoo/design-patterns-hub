Spring Boot is Spring Framework plus **opinionated, conditional defaults**: starters, auto-configuration, externalized configuration, an embedded server and production endpoints. These articles explain the mechanisms, so the "magic" becomes predictable.

> [!VERSION] Versions
> Written against **Spring Boot 4.1** (June 2026) on Spring Framework 7. Spring Boot 4.2 is due in November 2026. Version-specific behaviour is labelled.
