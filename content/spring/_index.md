This section explains Spring progressively: the container first, then web, persistence, security and production concerns. Version-specific behaviour refers to **Spring Boot 4.1** (built on Spring Framework 7). Articles link to the official reference documentation for details that change between releases.

> [!KEY] Patterns in Spring, stated precisely
> Spring is often described as "built on design patterns". The [Patterns in Spring](/spring/patterns-in-spring) subsection separates three claims:
> - where Spring *implements* a pattern, such as JDK and CGLIB proxies;
> - where its design *resembles* a pattern;
> - where a pattern is simply *useful in* Spring applications.
