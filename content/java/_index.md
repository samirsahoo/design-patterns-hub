This section teaches Java progressively, from how source code becomes bytecode to the Java Memory Model and virtual threads. All examples target **Java 21**, the LTS release used throughout this handbook. Features finalized after Java 21 are labelled with the release that finalized them.

> [!VERSION] Why Java 21?
> Java 21 is a long-term-support release with records, sealed classes, pattern matching for `switch` and virtual threads. It is the modern baseline that most production teams can adopt. Java 25 (September 2025) is the newer LTS. Where Java 25 changes recommended practice, articles say so explicitly.

The Java articles are being written in batches, and the two subsections list what is planned. Meanwhile, [Dependency Injection in Java](/spring/core/dependency-injection) and the pattern articles use plain, modern Java throughout.
