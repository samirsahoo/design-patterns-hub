Each case study covers:
- requirements and assumptions;
- components and communication patterns;
- data ownership;
- failure scenarios, scalability and trade-offs.

Each one also asks explicitly whether a modular monolith would be the better choice.

The first case study, [Designing an Order Management System](/system-design/case-studies/order-management-system), lives in the System Design section because it follows the full system-design framework.
