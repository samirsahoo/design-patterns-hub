Microservices are an architecture style in which a system is built from independently deployable services. Each service is owned by one team and has its own data. The style buys independent deployment and scaling, and it pays for them with distributed-systems complexity.

> [!KEY] The first question
> Before asking *how* to build microservices, ask *whether* to. [Microservices versus Modular Monolith](/microservices/fundamentals/microservices-vs-modular-monolith) covers that decision, and every case study in this section revisits it.
