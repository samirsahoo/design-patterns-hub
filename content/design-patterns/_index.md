Design patterns are named, reusable solutions to recurring object-oriented design problems. This section follows the classification in *Design Patterns: Elements of Reusable Object-Oriented Software* (Gamma, Helm, Johnson, Vlissides, 1994) — the "Gang of Four" (GoF). Each pattern is taught with a Java 21 example that CI compiles and runs.

Start with [What Are Design Patterns?](/design-patterns/what-are-design-patterns) and [SOLID Principles](/design-patterns/solid-principles). Then use the [overview of all 23 patterns](/design-patterns/gof-overview) as your map.
